Tenant isolation scenario

A tenant administrator needs to manage their own tenant without accessing another tenant’s records.

Verify membership and permissions for the selected tenant, then use that verified tenant context to access records. A tenant ID in a request selects a tenant; it does not establish access.

Verification should cover authorized requests, another tenant’s record ID, a modified tenant selector, and revoked tenant membership.

Access boundary

A tenant ID selects a tenant; membership and permissions establish access.
